MeshCore-Gateway – Web-Flasher

Heltec WiFi LoRa 32 V4 und V4-R8 · Firmware … · Quellcode

Vorbereitung

  1. Chrome oder Edge am PC/Mac (Web Serial; Firefox, Safari und Handys gehen nicht).
  2. Board per USB-C-Datenkabel anschließen, LoRa-Antenne vorher anschrauben.
  3. Findet der Browser kein Gerät: Taste PRG/BOOT gedrückt halten, kurz RST drücken, PRG loslassen.
Dieser Browser kann nicht auf USB-Geräte zugreifen. Bitte Chrome oder Edge am Computer verwenden.
